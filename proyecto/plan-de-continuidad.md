# Plan de continuidad

## Etapa 2 del sitio LUMÉ

En una segunda etapa se incorporarán la tienda y el catálogo de productos, las páginas individuales de cada vela, la personalización de productos, el carrito de compras y el proceso de pago.

También se podrán agregar funciones de suscripción a novedades, botones para compartir contenido en redes sociales, optimización SEO, reseñas de clientes y recomendaciones de aromas.

## Mantenimiento

- Realizar respaldos periódicos del sitio.
- Mantener WordPress, el tema y los plugins actualizados.
- Revisar el formulario de contacto.
- Comprobar los enlaces, las imágenes y el menú.
- Revisar el rendimiento del sitio.
- Comprobar que el sitio siga disponible en el hosting.

## Plan alternativo

Si el hosting actual presenta limitaciones para la tienda, los pagos o el correo electrónico, se migrará el sitio a un servidor compatible con WooCommerce, certificado SSL, SMTP y mayores recursos.
